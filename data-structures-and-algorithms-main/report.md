# Лабораторная работа №1

## Анализ временной сложности элементарных алгоритмов

**Вариант:** 20\
**Seed:** 50

------------------------------------------------------------------------

## Цель работы

Научиться определять временную сложность алгоритмов аналитически и
подтверждать полученные оценки экспериментальными измерениями.

------------------------------------------------------------------------

## Реализованные алгоритмы

В работе реализованы четыре алгоритма:

1.  Сумма элементов массива.
2.  Поиск максимального элемента массива.
3.  Подсчёт пар равных элементов массива.
4.  Бинарное возведение в степень с поддержкой вычислений по модулю.

------------------------------------------------------------------------

## Теоретическая оценка сложности

  Алгоритм                        Асимптотическая сложность
  ------------------------------- ---------------------------
  Сумма элементов массива         O(n)
  Поиск максимального элемента    O(n)
  Подсчёт пар равных элементов    O(n²)
  Бинарное возведение в степень   O(log n)

------------------------------------------------------------------------

# Анализ результатов эксперимента

## Сумма элементов массива

Экспериментальный наклон графика:

    0.965

Теоретическая оценка:

    O(n)

Полученное значение близко к 1, поэтому эксперимент подтверждает
линейную сложность алгоритма.

------------------------------------------------------------------------

## Поиск максимального элемента

Экспериментальный наклон:

    1.028

Теоретическая оценка:

    O(n)

Отклонение связано с особенностями выполнения Python, работой процессора
и кэшированием.

------------------------------------------------------------------------

## Подсчёт одинаковых пар

Экспериментальный наклон:

    1.998

Теоретическая оценка:

    O(n²)

Полученный результат практически совпадает с ожидаемым значением 2.
Алгоритм содержит два вложенных цикла, поэтому число операций растёт
квадратично.

------------------------------------------------------------------------

## Бинарное возведение в степень

Алгоритм использует метод последовательного квадрирования.

Эксперимент выполнялся с вычислением по модулю:

    1000000007

График построен в координатах:

    t(log₂ n)

Логарифмический алгоритм не анализируется через log-log график, так как
зависимость log(n) в таких координатах не даёт информативного линейного
наклона.

------------------------------------------------------------------------

# Проверка корректности

Были выполнены проверки:

-   пустой массив;
-   массив из одного элемента;
-   массив с одинаковыми элементами;
-   сравнение суммы с встроенной функцией sum;
-   сравнение максимума с функцией max;
-   сравнение бинарного возведения в степень с pow.

Результат:

    self_check: OK

------------------------------------------------------------------------

# Методика измерений

Использовались:

-   предварительный прогрев;
-   5 повторов каждого измерения;
-   медианное значение времени.

Такой подход уменьшает влияние случайных отклонений.

------------------------------------------------------------------------

# Объяснение расхождений между теорией и практикой

Теоретическая оценка Big-O показывает порядок роста алгоритма, но не
учитывает:

-   накладные расходы интерпретатора Python;
-   работу кэша процессора;
-   фоновые процессы операционной системы;
-   постоянные коэффициенты операций.

Поэтому экспериментальные значения могут немного отличаться от
идеальных.

------------------------------------------------------------------------

# Вывод

В ходе лабораторной работы были реализованы четыре алгоритма и проведён
анализ их временной сложности.

Экспериментальные результаты подтвердили теоретические оценки:

-   линейные алгоритмы имеют сложность O(n);
-   алгоритм с двумя вложенными циклами имеет сложность O(n²);
-   бинарное возведение в степень имеет логарифмическую сложность O(log
    n).

Полученные графики соответствуют ожидаемому поведению алгоритмов.
